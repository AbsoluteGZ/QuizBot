# Telegram-бот для викторины с использованием базы данных SQLite

Этот проект реализует Telegram-бота, который проводит викторину, сохраняя состояние игры и результаты в базе данных SQLite.

## Функциональность

Бот предлагает пользователю начать викторину.  Каждый вопрос викторины отображается с вариантами ответа в виде интерактивных кнопок.  Бот отслеживает правильные и неправильные ответы, сохраняя прогресс пользователя в базе данных.  После завершения викторины, бот сообщает пользователю общее количество правильных ответов.

## Зависимости

Необходимо установить следующие библиотеки:

```bash
pip install aiosqlite aiogram
```

## База данных

Бот использует базу данных SQLite (`quiz_bot.db`) для хранения:

* **Состояния викторины:**  Таблица `quiz_state` хранит `user_id` (идентификатор пользователя) и `question_index` (индекс текущего вопроса).
* **Результатов викторины:**  Таблица `quiz_results` хранит `user_id` и `correct_answers` (количество правильных ответов).

## Настройка

1. **Токен API Telegram:** Замените `"YOUR_TELEGRAM_BOT_TOKEN"` в файле `settings.py` на ваш собственный токен бота Telegram.
2. **Вопросы викторины:** Вопросы викторины хранятся в списке `quiz_data` в файле `main.py`.  Вы можете изменять и добавлять вопросы по своему усмотрению.  Каждый элемент списка должен быть словарем со следующими ключами:
    * `question`: Текст вопроса.
    * `options`: Список вариантов ответа.
    * `correct_option`: Индекс правильного ответа в списке `options`.

3. **Запуск бота:** Запустите скрипт `main.py`. Бот начнет работу и будет ожидать команд.


## Использование

1. Начните бота.
2. Отправьте команду `/start` или нажмите кнопку "Начать игру".
3. Бот задаст вопросы викторины по очереди.
4. Нажимайте на кнопки с вариантами ответа.
5. После ответа бот сообщит, правильный ли ответ был дан.
6. По окончании викторины, бот сообщит общее количество правильных ответов.

## Структура проекта

* `main.py`:  Основной скрипт бота.
* `db.py`:  Функции для работы с базой данных SQLite.
* `functions.py`:  Функции для обработки сообщений и кнопок.
* `settings.py`:  Настройки бота (API-токен).
* `questions.py`:  Список вопросов викторины (`quiz_data`).
